# Ball Platformer

A playable browser platformer made with plain HTML, CSS, and JavaScript.

## Play

Open `index.html` in a modern browser, or start a local server in this folder:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- Move: **A/D** or **←/→**
- Jump: **W**, **↑**, or **Space**
- Collect all five gems and reach the goal. Falling or touching spikes costs a life.
